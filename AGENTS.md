# Local development preference

On this machine, use `npm run dev:overlay` when starting Computerbug for development.
For the desktop app alone, use `npm run dev:desktop:overlay`.
Use windowed development mode only when explicitly requested.

# Commit and pull request attribution

Do not add Codex, ChatGPT, or other AI attribution to commit messages or pull
requests, including generated-by footers and co-author trailers.
